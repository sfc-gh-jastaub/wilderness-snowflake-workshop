Your Christmas assistant in CoWork

Overview

What you will build

  • Run one script that builds Wilderness's data in your account: 72 stores plus online, 1,200 products, three million sales lines since July 2024 and 20,000 customer comments.
  • Make the customer comments searchable with Cortex Search.
  • Teach the semantic view Wilderness's words: a return rate, synonyms and two answers you have checked.
  • Create the Wilderness Assistant and give it two tools: the numbers and the customer comments.
  • Put the assistant in CoWork, where the store managers work, and ask it the tent question.
  • Save a chart and schedule a question so the answer arrives by email.

What you use

Cortex Search Semantic views Cortex Analyst Cortex Agents Snowflake CoWork Artifacts Automations Agent skills

The situation

Christmas trading started on Sunday. Wilderness ordered tents 40% deeper than last year, but not the sleeping gear that goes with them, and the Summit 2P on the catalogue cover is coming back with broken poles. Martha Thompson, Chief Customer Officer, wants every store manager to get straight answers each morning.

Make customer feedback searchable

~7 min
What Cortex Search is

It makes unstructured data, such as free-text comments, available to an agent. The agent can then find and quote what customers said, as easily as it reads a number from a table.

Martha's store managers read the reviews that reach them. Twenty thousand comments from reviews, the returns desk and surveys do not reach anyone. Cortex Search finds comments by what they mean, not by exact words, so "the pole snapped" also finds "the hub cracked".

You build it over one text column with one form.

  1. Go to AI & ML » Cortex Search and select Create.
  2. Fill in the form with the values below. Select a value to copy it.
  3. Select Create.

CSS_CUSTOMER_FEEDBACK in the list of services. Indexing 20,000 comments takes about a minute.

Why a target lag

The service keeps itself in step with the table. With a lag of one day, comments added today are searchable by tomorrow, with no pipeline to run.

3

Teach the semantic view Wilderness's language

~10 min
What a semantic view is

It makes structured data, the tables of sales, returns and stock, available to an agent. It describes the data in Wilderness's terms: what a sale is, how a return links to a sale, what "return rate" means. The agent reads it to turn a question into the right query.

Setup created the semantic view SV_WILDERNESS_RETAIL over sales, returns, stock and the kit each store needs, with the joins between them. It does not yet know how Wilderness talks. You make three changes.

  1. Go to AI & ML » Cortex Analyst and open SV_WILDERNESS_RETAIL.
  2. Select Edit.

1. Add the return rate

Store managers ask about the return rate, and the semantic view only counts units returned. A return rate divides returns by sales, so it uses two tables. Add it as a metric of the whole view, not of one table.

FieldValue
NameRETURN_RATE
ExpressionDIV0(returns.total_units_returned, sales.total_units_sold)
DescriptionUnits returned divided by units sold

2. Add synonyms

Add each synonym to the field it belongs to.

FieldSynonym
products › CATEGORYtent
products › KIT_GROUPsleeping gear
products › IN_CHRISTMAS_CATALOGUEChristmas range
kit_cover › KIT_GROUPsleeping gear
returns › TOTAL_UNITS_RETURNEDreturns
inventory › AVG_WEEKS_OF_COVERstock cover

3. Add two verified queries

A verified query is a question with SQL you have checked. When someone asks something similar, Cortex Analyst starts from your SQL. Add both, each with its question and its SQL.

Question: What is the return rate by category?

sql
WITH sold AS (SELECT p.category, SUM(s.units_sold) AS units_sold
FROM __sales AS s
JOIN __products AS p ON s.sale_product_id = p.product_id
GROUP BY p.category),
back AS (SELECT p.category, SUM(r.units_returned) AS units_returned
FROM __returns AS r
JOIN __sales AS s ON r.return_sale_line_id = s.sale_line_id
JOIN __products AS p ON s.sale_product_id = p.product_id
GROUP BY p.category)
SELECT sold.category, sold.units_sold, COALESCE(back.units_returned, 0) AS units_returned, ROUND(COALESCE(back.units_returned, 0) / NULLIF(sold.units_sold, 0), 4) AS return_rate
FROM sold
LEFT JOIN back ON back.category = sold.category
ORDER BY return_rate DESC NULLS LAST

Question: Which states are short of sleeping gear, and by how much?

sql
SELECT st.state, COUNT(DISTINCT k.kit_cover_store_id) AS stores_short, SUM(k.shortfall_units) AS shortfall_units, SUM(k.basket_at_risk) AS basket_sales_at_risk_aud, MIN(k.run_out_week) AS earliest_run_out_week
FROM __kit_cover AS k
JOIN __stores AS st ON k.kit_cover_store_id = st.store_id
WHERE k.kit_cover_group = 'SLEEP' AND k.shortfall_units > 0
GROUP BY st.state
ORDER BY shortfall_units DESC NULLS LAST

Select Save.

You should see

The semantic view saves without errors and lists RETURN_RATE under its metrics and two verified queries.

Why verified queries matter later

They are answers you have checked. The agent reuses them today, and in Lab 3 they become the test the semantic view has to pass.

4

Create the Wilderness Assistant

~8 min
What a Cortex Agent is

It is the assistant itself. It reads a question, picks the right source for each part (the semantic view for numbers, Cortex Search for what customers said), gets the answers and writes one reply.

An agent decides which tool answers each part of a question, runs them and writes the answer. You create it now and give it tools in Step 5.

  1. Go to AI & ML » Agents and select Create agent.
  2. Set the database and schema to WILDERNESS_HOL.AGENTS, the agent object name to WILDERNESS_ASSISTANT and the display name to Wilderness Assistant. Select Create agent.
  3. On the agent page select Edit. Under Orchestration, set the orchestration model to claude-sonnet-4-6.
  4. Paste the response instructions below into Response instruction.
  5. Add the two sample questions below, then select Save.

Response instructions:

text
You help Wilderness Outfitters store managers and merchandisers through Christmas trading. Use plain Australian English and short sentences. Give the answer first, then the numbers behind it. Show money in AUD. Quote customers and documents word for word and name the source. If the data does not cover the question, say so. Do not use marketing language.

Sample question 1:

text
Tents are our big Christmas bet. Where will we still be holding tents on Boxing Day, where will we run out, and have we got the sleeping gear to go with them?

Sample question 2:

text
Customers are bringing the Summit 2P back. What are they saying, and is it worse for some batches than others?
Why the model is pinned

The agent uses one named model rather than "auto", so the evaluation runs in Lab 3 compare like with like.

7

Keep the answer and schedule it: artifacts and automations

~8 min

A chat answer disappears into the history. CoWork can keep a chart, called an artifact, or ask a question again on a schedule and email you the result, called an automation.

Save the chart as an artifact

  1. On the chart from Step 6, select Save.
  2. Open the Artifacts hub, then Saved, and open the chart.
  • The chart reruns its SQL when you refresh it, with your own access rights.
  • A question like "last 30 days" moves forward each time. Fixed dates stay fixed.
  • A shared conversation is different: it is a snapshot and never reruns.

Schedule the sleeping-gear question

  1. In the conversation, ask the question below.
  2. Confirm the schedule CoWork proposes.
  3. Open the Automations tab to see it with its next run time.
  4. Open the automation and select Run now, so you do not have to wait for the hour.
text
Send me the sleeping-gear shortfall by store every hour.
You should see

One saved artifact, and one automation marked Active with a next run time within the hour. A few minutes after Run now, an email with the sleeping-gear shortfall by store arrives at the address you verified. It also appears in the automation's run history.

It runs every hour until you change it

Each run re-asks the question as you, against the latest data, on your warehouse. Hourly is for today, so you see it work. In Lab 3 you count what it costs and move it to weekdays at 7am, the schedule a store manager would use. Cleanup deletes it.

Brief Martha: a skill that emails a report Optional

~10 min

The automation in Step 7 sends a summary, worded however the assistant likes that day. A skill makes Martha's briefing the same shape every time. It is a set of instructions in plain English, with a small script, kept in the workshop's Git repository. Any agent that references it uses it.

What a skill is

A folder with a SKILL.md file: a name, a description of when to use it, and the steps to follow. The agent reads the description of every skill it has and opens a skill only when a question needs it. This one gathers the morning's numbers with the agent's own tools, lays them out with a script, and emails the result.

Add the skill, and what it needs

  1. On the agent, select Edit and open Skills. Select Add Skill » Git, paste the path below and select Add Skill.
